# IEEE Nordic Test system

This is the Nordic variant detailed in the IEEE report "Test Systems for Voltage Stability Analysis and Security Assessment" located in https://resourcecenter.ieee-pes.org/publications/technical-reports/PESTR19.html

The data files are to be used with PFC (for the power flow) and RAMSES (for the dynamic simulations). Please check https://pyramses.sps-lab.org/
